Jira Opsidian

Overview

Jira의 업무 계층과 이슈 연결 관계를 한 화면에서 읽고 검토하는 개인 제품 콘셉트입니다. 왼쪽에서 Task·Sub-task·Epic을 탐색하고, 가운데에서 관계 맵을 확인하며, 오른쪽에서 선택한 이슈의 상세 내용을 읽습니다.

Problem

이슈 목록과 상세 화면을 오가면 업무 계층과 연결 관계를 함께 파악하기 어렵습니다. 여러 이슈가 어떤 에픽에 속하고 어떤 관계로 묶였는지 확인할 때 화면 전환과 기억에 의존하는 흐름도 생깁니다.

Approach

세 영역을 고정된 작업공간으로 나누고, 선택 상태를 서로 연결했습니다. 관계 맵은 이슈 연결을 묶거나 풀어서 필요한 구조만 남겨 볼 수 있게 구성했습니다.

  1. 왼쪽 이슈 트리에서 Task·Sub-task·Epic 탐색
  2. 가운데 관계 맵에서 연결 구조 확인
  3. 필요한 관계를 묶거나 풀어 구조 정리
  4. 오른쪽 상세 패널에서 선택한 이슈 검토
  • 왼쪽 · 이슈 트리 전체 Task·Sub-task·Epic을 계층 구조로 탐색합니다.
  • 가운데 · 관계 맵 이슈 간 연결을 표시하고 관계 그룹을 묶거나 풀어 봅니다.
  • 오른쪽 · 상세 패널 선택한 이슈의 상태, 담당자, 본문, 댓글과 활동을 확인합니다.
  • 현재 범위 개인 작업 흐름을 정리한 화면 콘셉트와 공개-safe 샘플 데이터 중심의 미리보기입니다.

Screen evidence

이슈 트리에서 대상을 고르고, 중앙 관계 맵에서 연결 구조를 읽은 뒤, 오른쪽 상세 패널에서 선택한 이슈의 내용을 확인하는 흐름입니다.
