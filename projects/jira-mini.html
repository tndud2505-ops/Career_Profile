Jira Mini

Overview

목록에서 담당자·상태·일정을 빠르게 수정하고 본문·댓글·첨부와 AI 서브태스크 초안까지 같은 리뷰 흐름에서 다룹니다.

Problem

기존 Jira 화면의 이동이 많으면 여러 하위 작업을 비교하고 최근 활동을 확인하는 데 집중하기 어렵습니다.

Approach

검색·필터·상위 업무 접기/펼치기를 먼저 제공하고 목록 빠른 수정과 상세 리뷰를 한 작업공간으로 연결했습니다.

  1. 업무명·담당자·상태 검색
  2. 하위 작업 범위 좁히기
  3. 목록에서 상태·일정 빠른 수정
  4. 상세·댓글·첨부·최근 활동 검토
  • 목록 가시성검색과 접기/펼치기로 비교할 업무 범위를 빠르게 좁힙니다.
  • 빠른 수정목록에서 담당자·상태·일정을 바로 바꿉니다.
  • 상세 리뷰본문·첨부·댓글·최근 활동을 같은 흐름에서 확인합니다.
  • UI stackReact UI와 Jira 연동으로 목록과 상세 상태를 연결했습니다.

Screen evidence

목록에서 업무 범위를 좁히고 빠르게 수정한 다음, 본문·댓글·첨부와 최근 활동을 같은 리뷰 흐름에서 확인합니다.
