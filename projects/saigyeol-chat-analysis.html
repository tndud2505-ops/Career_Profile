대화 분석

서비스 소개

카카오톡에서 내보낸 TXT로 대화 흐름을 살펴보는 분석 서비스입니다. 브라우저에서 참여자별 통계와 표현 신호, 대화 연결을 확인하고 결과의 원문 근거를 찾아볼 수 있습니다. 탐지 결과는 실제 감정이나 관계를 확정하는 판정이 아닙니다.

주요 기능

  • 파일 가져오기 — TXT의 메시지 수·참여자·대화 기간 확인
  • 분석 방식 — 문맥 모델 분석 또는 빠른 규칙 분석 선택
  • 결과 보기 — 사람별 통계·표현 신호 추이·방향별 대화 연결 확인
  • 근거와 기록 — 원문 대화 확인, 결과 기록과 이미지 공유
