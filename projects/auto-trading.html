Auto Trading

Overview

Kiwoom OpenAPI 기반 후보 상태 보드에서 실행 전 조건, 차단 사유, 보유 포지션, 최근 체결과 운영 로그를 분리해 확인하는 개인 검토용 주식 매매 자동화 도구입니다.

Problem

후보 탐색 정보와 실행 조건이 한 화면에 섞이면 왜 대기 중인지, 무엇이 차단됐는지, 실행 이후 어떤 상태가 남았는지 설명하기 어렵습니다.

Approach

추천 결과를 바로 실행으로 연결하지 않고, 상태 확인과 차단 사유 검토를 먼저 거치는 운영 흐름으로 나눴습니다.

  1. 후보 스냅샷과 현재 상태 확인
  2. setup·execution·CTX 상태 점검
  3. 차단 사유와 readiness gate 검토
  4. 운영 로그·보유·체결 상태 복기

Screen evidence

후보를 확인한 뒤 실행 전 조건과 차단 사유를 검토하고, 보유·체결·운영 로그로 상태를 복기하는 순서입니다.
