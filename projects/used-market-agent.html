USED PICK

개요

USED PICK은 중고나라·번개장터·헬로마켓·리씽크몰 상품을 한 화면에서 검색하고, 카테고리·가격·정렬 기준으로 결과를 비교하는 중고거래 통합 검색 사이트입니다.

해결할 문제

중고 상품이 플랫폼별로 흩어져 있으면 같은 검색어를 여러 사이트에서 반복하고 가격과 등록 시점을 따로 비교해야 합니다. 검색 시작점과 결과 확인 흐름을 한 화면으로 묶을 필요가 있었습니다.

구현 과정

상품 검색, 플랫폼 선택, 결과 필터와 정렬, 원문 확인이 한 흐름에서 이어지도록 구성했습니다.

  1. 상품명·브랜드·모델로 검색
  2. 통합 결과와 플랫폼별 결과 전환
  3. 카테고리·최소·최대 가격으로 범위 좁히기
  4. 추천순·최신순·가격순으로 비교 후 원문 열기
