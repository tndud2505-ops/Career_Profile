중고 매물 수집 에이전트

Overview

raw DOM에서 제목·가격·설명을 분리하고 중복과 불명확한 부품명을 필터링해 평균가와 낮은 가격 후보를 정리합니다.

Problem

좋은 중고 매물은 짧게 지나가고 가격 기준도 흔들려 사람이 검색어를 바꿔가며 계속 확인해야 했습니다.

Approach

키워드 수집, 가격 정규화, 중복 제거, 평균가 계산과 후보 리포트를 하나의 감시 흐름으로 묶었습니다.

  1. 키워드별 매물 수집
  2. 제목·가격·설명 분리
  3. 중복·불명확 항목 필터
  4. 평균가와 낮은 가격 후보 확인
  • raw DOM 수집페이지에서 제목·가격·설명을 분리해 원본을 보존합니다.
  • 정규화·필터가격 단위를 맞추고 중복과 불명확한 부품명을 걸러냅니다.
  • 가격 기준평균가와 후보 가격을 같은 기준으로 비교합니다.
  • UI stack수집 결과를 다시 검토하는 리포트 화면으로 구성했습니다.

Screen evidence

수집한 raw DOM에서 필요한 필드를 분리하고 중복·불명확한 항목을 정리한 뒤, 평균가와 낮은 가격 후보를 리포트로 확인합니다.
