일상 생활 자동화 에이전트

Overview

Discord Agent, Git Researcher, 논문 에이전트, Review Agent를 분리해 요청·근거·지식·품질 확인을 이어갑니다.

Problem

반복 작업이 한 번의 대화나 수동 실행으로 끝나면 다음 요청에서 같은 검색과 검토를 다시 해야 합니다.

Approach

외부 입력, 로컬 실행, 근거 저장, 품질 리뷰를 역할별 Agent 흐름으로 나누고 결과를 다음 요청에서도 다시 확인할 수 있게 했습니다.

  1. Discord 요청과 첨부 전달
  2. 전문 Agent 실행
  3. 결과·근거·지식 노트 저장
  4. Review Agent의 품질 검증
  • 입력 채널Discord 요청과 결과 확인을 한 진입점에서 관리합니다.
  • 전문 AgentGitHub 조사와 논문 요약을 목적별 흐름으로 분리합니다.
  • 근거 저장검색 결과와 요약을 지식 노트로 남깁니다.
  • 품질 리뷰Ruff·deptry·vulture 검사를 Review 흐름에 연결했습니다.

Screen evidence

Discord 요청이 전문 Agent 실행으로 이어지고, 검색·근거 저장·Review Agent 결과가 다음 요청에서 다시 사용되는 흐름입니다.
