C 코드 기반 가상 임베디드 교육 웹사이트 제작

실제 타겟 보드가 없어도 PSU/SCM에서 다루는 C 코드 흐름을 웹에서 가상으로 실행해 보는 교육용 사이트입니다. 코드를 실행하면 핀 상태, 레지스터 값, 그래프, 모터 회전이 함께 바뀌어 코드가 하드웨어 동작으로 이어지는 과정을 확인할 수 있습니다.

  • 에디터에서 C 코드를 작성하고 바로 가상 실행
  • 핀 상태와 레지스터 값 변화를 화면에서 확인
  • 그래프와 로그로 코드 실행 흐름을 추적
  • 모터 방향, 회전 상태, 전류 변화를 회로도에서 확인
문제 배경
실제 타겟 보드가 없으면 C 코드가 핀과 모터 동작으로 이어지는 과정을 교육하기 어렵습니다.
실제 결과
PSU/SCM C 코드 흐름을 가상으로 실행하고, 핀·레지스터·그래프·모터 상태를 한 화면에서 확인할 수 있게 만들었습니다.

멀티 에이전트 작업 하네스

큰 작업을 역할별 에이전트로 나누고 리뷰 근거와 결정 이력을 남기는 작업 보드

큰 작업을 하나의 AI 세션에 몰아주면 조사, 구현, 검증, 리뷰가 섞여 놓친 부분을 늦게 발견하기 쉽습니다. 이 보드는 작업을 역할별 방으로 나누고, 각 에이전트의 주장, 근거, 대기 상태, 후속 액션을 한 화면에 남겨 사람이 최종 판단하기 쉽게 만든 운영 화면입니다.

  • Chief, Feature, Test, Review 등 역할별 작업 분리
  • 이슈, 발견사항, 토론, 액션 큐를 한 화면에 기록
  • 리뷰 요청과 테스트 요청을 근거 스레드로 추적
  • 사람이 승인·보류·재배정할 수 있는 운영 흐름
문제 배경
AI에게 큰 작업을 맡길 때 가장 어려운 부분은 결과보다 과정입니다. 누가 무엇을 판단했고 어떤 근거로 보류됐는지 남겨야 했습니다.
실제 결과
역할별 에이전트의 상태, 리뷰 이슈, 토론, 후속 액션을 한 화면에 묶어 누가 무엇을 판단했고 어디서 막혔는지 바로 확인할 수 있게 했습니다.

중고거래 후보 수집·비교

중고매물 추적도구

같은 물건을 찾더라도 사이트마다 제목, 가격, 부품 포함 여부, 등록 상태가 달라 직접 비교하는 시간이 길어집니다. 이 도구는 허용된 범위에서 관심 후보를 수집하고, 중복을 정리한 뒤 가격 범위와 확인 메모를 한 화면에 모아 구매 판단이 아니라 후보 검토 시간을 줄이기 위해 만든 화면입니다.

  • 검색 키워드로 모은 후보를 같은 기준으로 정리해 가격 차이와 중복 여부를 바로 보여줌
  • 최근 올라온 매물 중 최저가와 가격대를 비교해 다시 볼 후보를 추림
  • 중복 매물과 관련 없는 매물을 제외하고 운영 메모 기록
  • 확인할 후보만 남겨 Discord 알림으로 전달
문제 배경
관심 매물이 여러 사이트에 흩어져 있으면 같은 검색을 반복하고, 가격이 싼 이유나 부품 포함 여부를 매번 다시 확인해야 했습니다.

주식 이론·조건 검색

주식 이론 기반 차트 추천 및 조건 검색 자동매매

원하는 조건으로 후보 종목을 찾고, 종목 상세에서 차트·거래량·박스권·매매 계획선을 함께 보며 주식 이론 기준에 맞는 구간을 검토하도록 만든 화면입니다. 단순 주문 화면이 아니라 후보 선정 이유, 차트 해석, 계좌 준비 상태를 나눠 보여줘 어떤 근거로 종목을 봤는지 다시 확인할 수 있게 했습니다.

  • 원하는 상세 조건으로 종목을 검색해 기본 검색보다 더 세밀하게 후보를 찾음
  • 주식 이론 기준으로 차트, 거래량, 박스권, 매매 계획선을 함께 확인
  • 계좌 상태와 실거래 모드를 확인한 뒤 자동매매 주문 흐름까지 이어서 지원
  • 주문 후보, 보유 포지션, 주문 이력을 탭별로 분리
문제 배경
자동매매 후보와 실제 주문 준비 상태가 한 화면에 섞이면, 어떤 종목이 왜 후보였고 실행 가능 상태였는지 나중에 추적하기 어렵습니다.
실제 결과
상세 조건 검색으로 후보를 좁히고, 차트 추천 근거와 자동매매 준비 상태를 나눠 보여줘 어떤 이유로 종목을 골랐고 실제 주문 가능한지 한눈에 확인할 수 있게 했습니다.

Jira 하위 작업 리뷰·진척 관리

JIRA 작업 리뷰 관리도구

일반 Jira는 기능은 많지만, 하위 작업 리뷰와 진행 확인만 자주 볼 때는 화면 이동과 로딩이 무겁습니다. 그래서 필요한 이슈만 빠르게 검색하고, 트리 구조로 묶어 보고, Sub-task 안에서 리뷰·진척도·첨부를 바로 확인할 수 있는 관리 화면으로 다시 정리했습니다. 팀마다 다른 메모 양식도 일정한 형식으로 맞춰 관리자가 읽기 쉽게 정리할 수 있게 했습니다.

  • 업무·담당자·상태 검색과 미완료, 완료, 최근 활동 필터
  • 무거운 Jira보다 빠르게 열리고, 필요한 이슈만 골라 한눈에 관리
  • Sub-task 안에서 리뷰 결과, 진척도, 일반 메모를 나눠 바로 확인
  • 기존 Jira 본문·첨부 구조와 호환돼 이미지·표·첨부를 그대로 이어서 사용
  • 팀마다 다른 작성 양식을 일정한 형식으로 맞춰 관리자가 보기 쉽게 정리
문제 배경
일반 Jira에서는 하위 작업 리뷰, 진척 공유, 첨부, 본문 수정 맥락이 여러 화면에 흩어져 프로젝트 상태를 빠르게 훑기 어려웠습니다.
실제 결과
검색·필터·트리형 이슈 목록·Sub-task 화면을 한 흐름으로 묶어 필요한 이슈만 빠르게 보고, 진척·리뷰·첨부를 한눈에 관리할 수 있게 했습니다.
